# أثير

أثير تطبيق لمشاهدة الأفلام والمسلسلات من إضافات ستريمو التي تستخدمها أصلًا. واجهته عربية بالكامل، ويعرض المحتوى في مشغل واحد بلا حاجة للتنقل بين تطبيقات أخرى. يتعامل مع ملفات MP4 وHLS وDASH وMKV، ويعرض الترجمة من الإضافات، ويتذكر مكان توقفك.

## لماذا تستخدمه

معظم إضافات ستريمو تعطيك رابطًا ثم تفتح مشغلًا خارجيًا أو متصفحًا. أثير يأخذ الرابط ويشغّله بنفسه، مع ترجمة واختيار جودة وسرعة وتقديم وتأخير للترجمة. وإذا كان الملف بصيغة MKV يحوّله أثناء التشغيل بدل أن يطلب منك تنزيله. كل ذلك داخل واجهة واحدة، وإعداداتك وإضافاتك تبقى محفوظة على جهازك.

## التثبيت

### على الآيفون كتطبيق ويب

افتح الرابط التالي في Safari:

<https://hfip.github.io/aether/>

ثم اضغط زر المشاركة واختر «إضافة إلى الشاشة الرئيسية». سيعمل كتطبيق مستقل، ويمكنك استخدامه بدون متجر.

### على الآيفون كتطبيق iOS

ملف التثبيت (IPA) يُبنى داخل GitHub ولا يحتاج منك Mac. نزّل آخر نسخة من تبويب Actions في المستودع، ثم ثبّتها بأحد البرامج التالية:

- SideStore أو AltStore: يوقّعان التطبيق على الجهاز بحساب Apple ID عادي.
- Sideloadly: يوقّع التطبيق من الكمبيوتر.

الملف غير موقّع، لذلك ستحتاج أداة توقيع أو شهادة خاصة بك. هذا طبيعي ولا يعني أن هناك مشكلة في البناء.

### على الكمبيوتر أو الأندرويد

استخدم نفس رابط الويب. لا يوجد تطبيق منفصل لهذه الأنظمة، والصفحة تعمل في المتصفح مباشرة.

## ما الذي يعمل

تصفح إضافات ستريمو والبحث فيها، قائمة المشاهدة، متابعة من حيث توقفت، تشغيل MP4 وHLS وDASH، وتحويل MKV أثناء التشغيل. الترجمة تعمل بصيغ SRT وVTT، مع ضبط الحجم واللون والتوقيت. كذلك تجد سرعة التشغيل وملء الشاشة ومؤقت النوم وصورة داخل صورة والانتقال التلقائي للحلقة التالية.

## أشياء يجب معرفتها

- بعض السيرفرات تمنع قراءة ملف MKV من المتصفح. في هذه الحالة يظهر لك خيار النسخ إلى AetherPlayer.
- ملفات DRM وDolby Vision وTrueHD لا تعمل داخل WebKit، وتحتاج مشغلًا أصليًا.
- تشغيل DASH وMKV يحتاج iOS 17.1 أو أحدث.
- أول تشغيل لهذين النوعين يحمّل مكتبتين من الإنترنت، فتحتاج اتصالًا في تلك المرة.
- أثير لا يستضيف أي فيلم أو مسلسل. كل المحتوى يأتي من الإضافات التي تضيفها أنت.

## للمطورين

### البناء محليًا

```sh
npm ci
npm run build     # ينتج dist/index.html كملف واحد
npm run preview   # معاينة على http://localhost:4173
```

البناء يستخدم Rollup بنسخة WebAssembly وSucrase لتحويل JSX، لذلك لا يحتاج أدوات أصلية ويعمل حتى على iPad. لا تحتاج Xcode لبناء نسخة الويب.

الملف الناتج واحد لأن GitHub Pages يخدمه بسرعة، ولأن غلاف WKWebView يستطيع تحميله من داخل الحزمة بلا طلبات محلية ولا مشاكل CORS.

### بناء IPA

الورك `iOS IPA` في `.github/workflows/ios.yml` يعمل على `macos-15`، يبني الويب، ينسخه إلى `ios/Aether/Web/`، يولّد مشروع Xcode ثم يبني نسخة غير موقّعة ويجمعها في `Aether-unsigned.ipa`. نزّلها من Artifact باسم `Aether-unsigned-ipa`.

للبناء على Mac:

```sh
brew install xcodegen
./scripts/build-ios.sh
open ios/Aether.xcodeproj
```

اختر Team وBundle Identifier ثم شغّل على جهازك. غيّر `PRODUCT_BUNDLE_IDENTIFIER` في `ios/project.yml` إذا أردت معرّفًا مختلفًا.

### نشر الويب

الورك `Web` في `.github/workflows/pages.yml` ينشر `dist` على GitHub Pages مع كل دفعة إلى `main`. فعّل Pages مرة واحدة من Settings ثم Pages واختر المصدر GitHub Actions.

### مزامنة المصدر

`src/app/` هو نفس مصدر التطبيق المصغّر بلا تعديلات. لتحديث أحدهما من الآخر:

```sh
# من التطبيق المصغّر إلى المستودع
cp ~/apps/aether/{App.jsx,api.js,components.jsx,media.js,player.jsx,player-settings.jsx,prefs.js,remux.js,store.js,style.css,subtitles.js,views.jsx} src/app/

# من المستودع إلى التطبيق المصغّر
cp src/app/*.{js,jsx,css} ~/apps/aether/
```

بعدها شغّل `npm run build`.

### البنية

```
src/app/            مصدر التطبيق
src/main.jsx        نقطة تركيب React للويب
index.html          قالب الصفحة
scripts/build.mjs   بناء ملف واحد والأيقونات
scripts/icon.mjs    توليد أيقونات PNG برمجيًا
public/             manifest وأيقونة SVG
ios/project.yml     مشروع XcodeGen (iOS 17+، iPhone وiPad)
ios/Aether/         SwiftUI وWKWebView
.github/workflows/  نشر Pages وبناء IPA
```
